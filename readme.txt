== Description ==

The Southern Destinations 2026 WordPress block theme — a Full Site Editing theme for Southern Destinations, a South African inbound tour operator.

The theme carries design only: theme.json tokens, block and section styles, patterns, template parts and templates. Proprietary behaviour — post types, expiration rules, WETU import, form handlers, search integration and CRM routing — lives in the companion Southern Destinations block plugin. The test applied throughout: if deactivating the theme would break it, it does not belong in the theme.

Post types for Accommodation, Destination and Tour are supplied by the LSX Tour Operator plugin; the theme provides their templates and patterns.
